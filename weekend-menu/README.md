# Меню выходного дня

Личное PWA: меню на выходные → готовый список покупок за минуту.
Реализует MVP из PRD (F1–F9): активная неделя, быстрое добавление, библиотека блюд,
меню Сб/Вс, сборка и правка списка, режим магазина, офлайн, история.

## Запуск

```bash
cd weekend-menu
npm install
npm run dev       # разработка
npm test          # тесты (сборка списка, парсер, неделя, база)
npm run build     # прод-сборка в dist/ (PWA + service worker)
npm run preview   # посмотреть сборку
```

Деплой: Vercel / Netlify, root directory — `weekend-menu`, build — `npm run build`, output — `dist`.
На телефоне: открыть сайт → «На экран Домой» — приложение работает без интернета.

## Как устроено

| Что | Где |
|---|---|
| Хранение (IndexedDB через Dexie), все действия | `src/db.js` |
| Сборка списка покупок (чистая функция) | `src/lib/shopping.js` |
| Ввод ингредиента одной строкой («грудка копчёная 2 шт») | `src/lib/parse.js` |
| Неделя: ближайшие Сб+Вс, закрытие после Вс 23:59 | `src/lib/week.js` |
| Первичная догадка отдела для нового продукта | `src/lib/aisleGuess.js` |
| Экраны: Меню · Покупки · Блюда · История + карточка блюда | `src/screens/` |

Список покупок не хранится — он вычисляется из меню. В базе лежат только ручные правки
(`shoppingOverrides`: «есть дома», «куплено», своё количество, свободные позиции),
поэтому они не теряются при изменении меню.

Резервная копия: экран «История» → «Экспорт JSON» / «Импорт».

## Решения по открытым вопросам PRD (можно поменять)

- **Закрытие недели** — автоматически после воскресенья 23:59 (как в F1).
- **Количества** — строго число + единица в библиотеке; в списке покупок количество можно
  переписать свободным текстом («пакет», «немного»).
- Семейный доступ, места покупки, порции — не делала, это вне MVP.

Из v1.1 уже есть пометка «давно не готовила» (30+ дней) в библиотеке.
